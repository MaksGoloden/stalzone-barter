#### ☢️ STALZONE — Справочник бартера и сборок (Онлайн + Офлайн)

Интерактивный справочник по оптимальным веткам бартера, обвесам и сборкам снаряжения для игры **STALZONE (Steam)**. Работает как в браузере, так и полностью автономно без подключения к интернету (идеально для поездок в метро или мест без связи). 

#### ✨ Возможности

* **Переключатель фракций:** отдельные ветки и точные названия брони для **Сталкеров** и **Бандитов**.
* **Фильтрация по категориям:** Основное оружие, Вторичное, Броня, Контейнеры.
* **Живой поиск:** мгновенный поиск по названию предмета, этапу прокачки или нужному обвесу.
* **Полный офлайн-режим:** весь справочник упакован в один легкий HTML-файл, который открывается на любом телефоне (Android / iOS) или ПК без интернета.

#### 🌐 Онлайн-версия и скачивание

* **Открыть сайт в браузере:** https://maksgoloden.github.io/stalzone-barter/
* На главной странице сайта доступна кнопка **«Скачать офлайн-версию»** — сохраните файл на телефон и открывайте его через любой браузер.

#### 🛠 Как обновить базу предметов (для разработчиков)

База снаряжения генерируется с помощью Python-скрипта build_app.py без использования сторонних библиотек: 

1. Отредактируйте список BARTER_DATA в файле build_app.py.
2. Запустите скрипт: 

bash

python build_app.py

Используйте код с осторожностью.

Скопировать код в буфер обмена.
3. Скрипт автоматически пересоберёт актуальный HTML-файл с новыми предметами и обвесами.

#### 📂 Структура репозитория

* index.html — веб-версия справочника для GitHub Pages с кнопкой скачивания.
* stalzone_offline.html — автономный файл для скачивания и работы без интернета.
* build_app.py — Python-генератор справочника.
